# GUI 검수 체크리스트 (브라우저 검수용)

대상: http://localhost:8502 (`integration/heemin-team-20261114`, 커밋 없이 작업 트리 상태)
재시작: `.venv/bin/streamlit run app.py --server.port 8502 --server.headless true` (이 프로젝트 폴더에서)
자동 검증 결과: `pytest` 60 passed (2026-11-14, 사업 소개·편집 개선 후). 아래는 자동 테스트가 보지 못하는 화면 확인 항목입니다.

## 데스크톱 (1280px 이상)
1. 첫 화면: 아이보리 배경, 네이비 글자. 왼쪽 문구 : 오른쪽 예시 도넛 ≈ 1.618 : 1. 주 버튼은 '투자 성향 진단 시작하기' 하나.
2. 상단 메뉴: 성향 진단(진단 후 '내 추천') · 나만의 포트폴리오 제작하기 · 기업 분석. 로고 클릭 시 첫 화면.
3. 진단: 예산 화면(빠른 선택 10만원/100만원/1,000만원/3,000만원) → 질문 1~7이 한 화면에 하나씩, 고르면 다음으로 넘어감. '이전'으로 돌아가면 고른 답이 남아 있음.
4. 결과(예: 모든 답 ②): "위험 중립형 투자자", 추천 자산배분 성장형, 점수 막대 위 표시. 주 버튼 '나만의 포트폴리오 제작하기'.
5. 색: 자산군 도넛·범례·상품 도넛·표 점·금액 막대가 주식 빨강/주황, 채권 파랑, 다른 자산 초록, 자산배분 보라, 현금 회색으로 일치하는지. 무지개색 없음.
6. 상품 표: 상위 6개 + "외 N개" + '전체 N개 보기' 버튼, 각 행 한 줄 부가정보(자산 종류 · 설명 · 코드). 캡션 "2026.11.13 종가 기준 · 원화 · 1주 단위 · 수수료·세금 제외", 팩터 종목이 있으면 "2026.10.30 종가", 미국 종목이 있으면 환율 환산 문구.
7. 과거 성과 카드: 2023.11.14 ~ 2026.11.13, 추천 구성 vs 단기채권 ETF 선 그래프, 주의 한 줄.
8. "왜 이렇게 추천했나요?"에 강의·수업·공분산·SLSQP 같은 단어가 없는지.
9. 제작 화면(2차 개편): 맨 위 요약(예산·담은 비중 막대·실제로 사는 돈·남는 현금). 왼쪽 목록: 자산 종류 필터(전체/채권/주식/다른 자산/자산배분), 한 번에 5행 + '더 보기', 행마다 슬라이더(0.5% 단위)와 숫자 칸(±1, 0.01%)이 서로 맞춰지는지, 적용 버튼 없이 바로 반영되는지. 합계 100%에서 그 상품만 멈추고 다른 상품은 안 바뀌는지. '추천에 없던 ETF 더하기'로 더하면 0%로 목록에 들어오는지. 오른쪽 '추천안과 비교' 패널이 목록 바로 오른쪽 위에 있고, 1280px에서 목록을 스크롤해도 따라오는지(sticky), 768px·390px에서는 고정이 풀리고 한 열인지. 탭: 구성 차이 / 과거 성과(선 그래프 + 수익률·변동성·최대 낙폭 표) / 구성 도넛. 실제 매수표·CSV·낱말 풀이는 아래 펼침. 필터 전환·결과 화면 왕복 뒤에도 값 유지.
10. 기업 분석: 검색 826개(국내 806 + 미국 20). 선택한 기업 이름 아래 '이 회사는 무슨 일을 하나요?' 1~2문장 + 태그 + 출처(KIND 상장법인목록·수집일·홈페이지 / 미국은 공식 페이지 또는 SEC 10-K·확인일). 국내는 '상장법인목록 원문 보기' 펼침, 매출·영업이익·부채비율 차트(억원). 미국(예: 엔비디아·테슬라)은 소개는 보이고 재무는 '아직 없어요' 안내만, 차트 없음. KR모터스(000040) 같은 이름 불일치 회사는 '기업 소개 미확보'. 화면에 '천원'·파일 경로가 없는지.
10-1. 결과 상품 도넛에 회색 '현금' 조각이 있어 전체 100%인지.

## 모바일 (390px)
11. 첫 화면·결과·제작·기업 분석이 한 열로 접히고 가로 스크롤이 없는지. 표는 가로 스크롤 박스 안에서만 스크롤.

## 성향·예산 조합 (권장)
| 답 | 점수 | 기대 성향 / 배분 |
|---|---|---|
| 모두 ⑤ | 0 | 안정 추구형 / 안정형 (개별 종목 0개) |
| 모두 ③ | 14 | 위험 중립형 / 안정성장형 |
| ①×3, ②×1, ③×3 | 21 | 위험 중립형 / 성장형 |
| ①×6, ②×1 | 27 | 공격 추구형 / 공격형 |

각 성향을 예산 10만원·100만원·1,000만원으로 확인합니다. 10만원은 0주 상품이 많고 현금이 큰 것이 정상이며 안내 문구가 떠야 합니다.
