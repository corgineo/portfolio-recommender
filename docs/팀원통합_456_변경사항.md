## 9. Codex 1차 검수 보완 (2026-11-14)

1. **제작 화면 슬라이더 1개**: 공격형에서 슬라이더 27개가 그려지던 것을 "① 상품 고르기(selectbox) → ② 슬라이더 하나"로 바꿨습니다.
   - 모든 상품 비중은 위젯 key가 아니라 `session_state['existing_recommendation_c_model']['w']`(코드 → %)에 보관합니다. Streamlit은 그려지지 않은 위젯 key를 지우므로, 슬라이더 값은 매번 model에서 채우고 `on_change`에서 model에 다시 씁니다. 고른 상품도 model['pick']에 저장해 다른 페이지 왕복 후 되살립니다.
   - 상한은 팀 규칙 그대로(`cap_value` = 100 − 다른 상품 합계). 슬라이더 아래 한 줄: "이 상품은 최대 X%까지 담을 수 있어요. 다른 상품 비중을 줄이면 더 담을 수 있어요."
   - 추천에 없던 ETF도 같은 selectbox에서 고릅니다(라벨 "추천에 없던 상품"). 되돌리기는 model을 추천 비중으로, 서명(추천 비중·상품) 변경 시 자동 초기화, 예산 변경은 비중을 유지합니다. 도넛·표·현금·성과 비교는 model 값으로 즉시 다시 계산합니다.
2. **결과 상품 도넛에 현금 포함**: 현금(회색) 조각을 넣어 전체 100%가 되게 했습니다. 가운데 예산·표의 목표 비중과 일치합니다.
3. **추천 이유 문구 정확화**: 개별 종목이 없는 이유를 팀 공식(주식몫×0.5÷3%, 최대 10)으로 구분합니다 — 성향상 0개(안정형) / 예산 부족으로 0개 / 예산 때문에 일부만(예: 공격형 10만원 7개 대신 2개). 3% 규칙은 "자산군에 상품이 하나만 남으면 3%보다 작아도 그대로 담아요"라는 예외를 실제 해당 상품 이름과 함께 표시합니다.
4. **기업 분석 자료 없음 유지**: 결과 화면에서 미국 종목(예: Nvidia)을 골라 들어오면 매번 "선택한 기업 Nvidia (NVDA)" 머리글 + "재무 자료가 없어요" 경고만 보이고, 국내 다른 회사로 바꿔 보여 주지 않습니다. 사용자가 '다른 기업 검색하기'를 눌러야 검색창이 열립니다. 국내 기업은 차트 위에 "선택한 기업 이름 (코드)"를 크게 표시합니다. 화면 캡션의 내부 변환식(천원÷100,000)과 파일 경로는 지우고 '단위 억원'만 남겼습니다(`to_eok`, 이 문서의 설명은 유지).
5. **푸터**: 파일 경로를 지우고 "가격: FinanceDataReader · 날짜 종가까지 · 원화(미국은 환율 환산) · 재무: 국내 상장사 연간 자료"만 표시합니다.
6. **테스트 추가**: 슬라이더 1개, 상품 전환 후 값 유지, 결과↔제작 페이지 왕복 유지, 상한(남은 한도까지)·안내 문구, 추천에 없던 ETF 추가와 표 반영, 예산 변경 시 유지, 되돌리기, 성향 변경 시 초기화, 현금 포함 도넛(합 100%·회색), 개별 종목 0/일부 설명, 미국 종목 자료 없음 유지·명시적 검색 전환, 국내 기업 미리 선택, 푸터 경로 비노출, **팀원 core 12조건이 `tests/data/team_core_baseline.json`(= /tmp/team_core_baseline.json 복사본)과 picks·비중 완전 일치**.
