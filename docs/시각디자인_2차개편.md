# 시각 디자인 2차 개편 (2026-11-14)

## 목표
- '나만의 포트폴리오 제작'을 서비스 핵심 기능으로 전면에 둠 (홈 1순위 CTA · 상단 메뉴 강조 칩 · 결과 화면 맨 위 CTA · 전용 페이지).
- '계산 방법과 자료 기준' 섹션 제거. 기준일·통화·환율·과거 성과 한계는 각 표·차트 옆 짧은 캡션으로만 남김.
- 그래프·도형·표로 "내 돈이 얼마, 어디에 얼마씩, 바꾸면 어떻게"를 한눈에.
- 계산(recommender.py · service.py · portfolio_core.py · data/)은 그대로. 같은 입력이면 같은 결과.

## 디자인 시스템
| 역할 | 값 |
|---|---|
| 바탕 / 면 / 보조 면 | `#F7F4EE` 웜 아이보리 / `#FFFFFF` / `#EFEAE1` |
| 글자 | `#16213B` 잉크 네이비 · `#3B4762` · `#5E667C` (아이보리 위 약 5:1) |
| 브랜드 | `#2E5B7F` 미네랄 블루 (CTA·현재 진행·포커스), 옅은 `#E3ECF3` |
| 주의 | 면 `#FBF1DC` · 글자 `#7A4A0B` |
| 자산 색 (불변) | 채권 `#2563eb` · 주식 `#ef4444`+주황 · 다른 자산 `#16a34a` · 묶음 `#8b5cf6` · 현금 `#98a2b3` |

- 브랜드 색은 저채도, 자산 색은 고채도로 역할을 분리. 로고·메뉴·버튼에는 자산 색을 쓰지 않음.
- 색 옆에는 항상 이름·%·금액을 함께 표시 (W3C WCAG 2.2 Understanding 1.4.1 Use of Color).
- 간격 8px 체계, 글자 13·15·17·21·27·34·44px, 숫자는 `tabular-nums`, 모서리 12/16/20px, 선 1px.
- 배치: 데스크톱 주:보조 = 8:5 (약 1.618:1, 사용자 요청에 따른 레이아웃 기준). 900px 이하는 한 열로 쌓음.
  중요한 것부터 위·왼쪽에, 관련 내용은 한 면에 묶고, 세부는 펼쳐 보기로 (Apple HIG Layout 참고).
- `.streamlit/config.toml` 테마도 같은 팔레트로 바꿔 처음 접속할 때 흰 바탕이 보이지 않게 함.

## 화면별 구조
- **홈**: 8:5 히어로 — 왼쪽 카피 + `나만의 포트폴리오 만들기`(primary), 오른쪽 '예시' 표시가 붙은 배분 도넛 + 금액 범례. 아래는 3단계 여정 띠(3단계 '제작' 강조).
- **나만의 포트폴리오 (진단 전)**: 소개·시작 화면. 3단계, "7문항 성향 진단이 필요" 안내, 제작 공간 '화면 예시'(맞춤 구성 아님 명시). `성향 진단하고 만들기 시작` → `after_quiz='mock'` → 진단을 마치면 제작 공간으로 바로 감. 진단을 일부 했다면 "이어서" 문구와 함께 답하지 않은 문항부터 시작.
- **나만의 포트폴리오 (진단 후, 워크벤치)**: 머리(제목 · 출발 성향 · 되돌리기/결과) → 조절 패널 38% (담은 비중 막대 → ①상품 고르기 → ②슬라이더 → 금액 한 줄 → 더하기·빼기 / 제작 예산) | 프리뷰 62% (KPI 3개: 제작 예산 · 실제로 사는 돈 · 남는 현금 → 상품별 도넛 + 자산 종류별 '내 비율 막대 vs 추천 세로선' → 상위 6개 수량표 + 현금). 아래 펼쳐 보기: 전체 표·CSV·상세, 추천과 비교, 과거 비교, 낱말 풀이.
- **결과**: 8:5 머리(성향 · 예산/기간/범위 칩 · 제작 CTA | 0~28점 점수 막대) → ① 큰 도넛 + 금액 범례 (목표 비율 금액임을 캡션으로) → ② KPI(실제로 사는 돈 · 남는 현금 · 담는 상품 수) + 금액 막대가 들어간 상위 5개 표 + 전체 보기 → 어두운 CTA 띠 → 펼쳐 보기(상품별 비중, 과거 계산, 추천 근거).
- **상품 탐색**: 자산 색 범례 + 검색 카드 + 종류별 행(왼쪽 자산 색 띠 + "주식 · ETF" 글자 라벨).
- **상품 상세**: 머리 카드(왼쪽 이름·설명, 오른쪽 '꼭 알아 둘 점', 위 띠는 자산 색) → 가격 차트 8 : 핵심 수치 5 → 재무 막대 8 : 매출·영업이익 5. 부채비율·원표는 펼쳐 보기.
