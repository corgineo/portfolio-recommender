## 2. 글자 잘림 · 세로 가운데 (`assets/style.css`, 기존 규칙 수정 위주)
| 원인 | 조치 |
|---|---|
| Streamlit 1.66 버튼 글자가 `stMarkdownEllipsis`(nowrap+overflow hidden+…)로 감싸짐 | 버튼·세그먼트·탭·펼침 제목 안 글자 칸만 `white-space normal / overflow visible` (본문 영향 없음) |
| 버튼 p 가 전역 `p{line-height:1.6}` 상속 | 버튼/탭/펼침 p: `margin 0; line-height 1.35`, 버튼 `inline-flex; align-items/justify-content center; height auto` |
| 숫자 입력 22px + 고정 `height:56px` + ± 버튼 → 편집 행에서 `37.22`가 `37.2`로 잘림 | 컨테이너 flex, input `flex 1 1 auto; min-width 0; line-height normal; 세로 padding 0`(가운데), ± 버튼 `flex 0 0 auto` 고정 폭. 편집 행은 16px · ± 26px |
| 펼침 제목·라디오 카드 세로 정렬 | `display:flex; align-items:center` |
| 세그먼트(필터) 버튼 | 줄바꿈 허용(`flex-wrap`), 자동 높이 |

- 내비 메뉴는 기존대로 한 줄(`nowrap`) + 모바일 가로 스크롤(숨김 아님).
- 상품 둘러보기 카드 버튼(`st-key-base_/cat_`)은 기존 왼쪽 정렬 유지(선택자 우선순위가 더 높음).
- 전역(universal) 규칙 추가 없음 → Plotly/SVG/스크린리더 문구 영향 없음. 색상 변수 변경 없음.
