1투자성향과 해시태그

화면 위치: 결과 화면 맨 위 남색 카드

쓴 개념
  • 팀 기획 이 부분은 강의 개념이 아니라 서비스 설계예요.
  • 팀 PDF 안정형 · 안정성장형 · 성장형 · 공격형 4가지 구분은 팀 PDF의 법률신문 기사 기준이에요.

어떻게 계산했나요

  1. 설문 5문항의 보기를 위에서부터 1~4점으로 매겨요. 보수적인 답일수록 낮은 점수예요.
  2. 더한 점수로 나눠요: 5~8 안정형 9~12 안정성장형 13~16 성장형 17~20 공격형
  3. 투자 기간이 1년 미만이면 한 단계 보수적으로 낮춰요.
  4. 해시태그는 결과 비중을 보고 규칙대로 붙여요. 예: 해외 주식이 국내보다 많으면 #글로벌분산, 위험균형 모형이면 #위험균형
실제 숫자

3 + 3 + 3 + 3 + 3 = 15점 → 성장형

2예상 연수익률 · 변동성

화면 위치: 남색 카드 아래 숫자 4개 중 가운데 두 개

쓴 강의 개념
  • 금융통계_2026.ipynb 셀14 일간수익률 pct_change() = 어제 대비 오늘 몇 % 변했나
  • 금융통계_2026.ipynb 셀36 변동성 연율화 daily_ret.std() * np.sqrt(240)
  • 자산배분모형_종합 셀61 기대수익률 연율화 mean() * 240

어떻게 계산했나요

  1. ETF 8종의 최근 3년 일간수익률을 구해요.
  2. 상품별 일간수익률 × 추천 비중을 더해서 내 포트폴리오의 일간수익률을 만들어요.
  3. 예상 연수익률 = 일간 평균 × 240 (1년 = 240거래일)
  4. 변동성 = 일간 표준편차 × √240 흔들림은 기간의 제곱근에 비례해서 커져요.
쉽게 말하면

연수익률은 "1년에 평균 얼마나 늘었나", 변동성은 "1년 수익이 평균에서 보통 얼마나 오르내리나"예요. 변동성이 클수록 위험해요.

실제 숫자 (성장형)

예상 연수익률 8.7% · 변동성 4.5%

3최대 낙폭 (MDD)

화면 위치: 숫자 4개 중 맨 오른쪽 · 성과 비교 카드의 "가장 크게 떨어졌을 때"

쓴 강의 개념
  • 성과평가_백테스팅 PDF p.12 MDD(최대낙폭) = 투자 기간에서 고점부터 저점까지의 최대 누적 손실
  • 성과평가_백테스팅 PDF p.13 누적성과 index_100 = (1 + ret).cumprod() * 100
    고점 = expanding().max() → 사이트는 같은 뜻의 cummax() 사용

어떻게 계산했나요

  1. 포트폴리오 일간수익률을 차례로 곱해서 누적성과를 만들어요. 시작 = 100.
  2. 날마다 "그날까지의 최고점"을 구해요.
  3. 누적성과 ÷ 그때까지 최고점 − 1 이 하락률이고, 그중 가장 작은 값이 MDD예요.
쉽게 말하면

등산하다 가장 높은 곳에서 가장 깊은 골짜기까지 내려간 깊이예요. "최악의 순간에 얼마나 잃었나"를 보여줘요.

실제 숫자 (성장형)

2026.6.22 고점 → 2026.10.22 저점, −4.7%
1,000만원이면 약 47만원이 줄어든 적이 있어요.

4상품별 비중 (도넛 차트)

화면 위치: 결과 화면 왼쪽 카드 · 사이트의 핵심 계산

쓴 강의 개념 (7주차 자산배분)
  • 자산배분이해_적용 PDF p.3~4 포트폴리오 위험 √(wᵀΣw)
  • PDF p.21 · p.31 최소분산 포트폴리오
  • PDF p.25~27 리스크 패리티 (위험기여도 RC)
  • 자산배분모형_종합 셀35·43 같은 함수 구조
  • 6주차 최적화_기초 셀5 scipy.optimize.minimize, SLSQP, 'eq' 제약, bounds

어떻게 계산했나요

  1. 최근 3년 일간수익률로 공분산 행렬(× 240)을 만들어요. 상품끼리 "얼마나 같이 움직이나"를 모은 표예요.
  2. 자산군 안에 상품이 여러 개면 모형으로 비중을 정해요.
    안정형 · 안정성장형 → 최소분산: 전체 흔들림 √(wᵀΣw)가 가장 작게
    성장형 · 공격형 → 리스크 패리티: 상품마다 위험기여도가 같게
  3. 조건은 비중 합 = 1 0 ≤ 비중 ≤ 1 (공매도 없음). 컴퓨터가 비중을 조금씩 바꿔 가며 답을 찾아요(SLSQP).
  4. ⑤의 자산군 비율 × 자산군 안 비중을 곱해서 상품별 최종 비중을 만들어요.
실제 숫자 (성장형 · 리스크 패리티)

원유(변동성 40.2%)와 달러(9.0%) → 원유 = 9.0 ÷ (40.2 + 9.0) = 18.3%, 달러 81.7%
통안채 33% = 채권 24% × 100% + 자산배분 10% × 91.7%

5자산군별 비중 (가로 막대)

화면 위치: 결과 화면 오른쪽 카드

쓴 강의 개념
  • 종목선정_포트폴리오 PDF p.25 마코위츠 포트폴리오 이론
  • PDF p.28 분산투자와 체계적 · 비체계적 위험
  • 자산배분이해_적용 PDF p.5~7 상관관계와 투자비중에 따라 위험이 줄어드는 정도
  • 팀 PDF 성향별 비율 숫자 자체는 법률신문 기사 표

어떻게 계산했나요

  1. 성향에 맞는 줄을 팀 PDF 표에서 가져와요. 성장형 = 채권 24% · 주식 26% · 대안 30% · 자산배분 10% · 현금 10%
  2. 막대 아래 작은 글씨는 그 자산군 안에서 1% 넘게 담긴 상품이에요.
쉽게 말하면: 왜 나눠 담나요?

서로 다르게 움직이는 자산을 섞으면 하나가 떨어질 때 다른 하나가 버텨 줘서 전체 흔들림이 줄어요. 다만 금리 · 경기처럼 시장 전체를 흔드는 체계적 위험은 섞어도 남고, 회사 하나의 사고 같은 비체계적 위험만 줄어요.
