## 3. 나만의 포트폴리오 편집 (요청 3)

- 드롭다운 1종목 방식을 없애고, **자산 종류 필터(전체/채권/주식/다른 자산/자산배분, 개수 표시)** + **상품 목록(한 번에 5행, '더 보기'로 5개씩, '접기')**.
- 각 행: 색 점 · 상품 이름 · 코드 · 자산 종류 · "추천 x% → 내 y% · ±차이" · **짧은 슬라이더(0.5% 단위)** + **정확한 숫자 입력(±1 버튼, 0.01% 표시·입력)**. 둘은 같은 값으로 즉시 동기화되고 적용 버튼이 없습니다.
- 100% 상한: 팀 규칙 그대로(바꾼 상품만 '100 − 다른 상품 합계'로 자름). **다른 상품은 자동으로 바꾸지 않습니다.** 잘리면 안내 문구가 나옵니다.
- 상태: 모든 비중·더한 ETF·필터·더보기 상태는 `session_state['existing_recommendation_c_model']`에 보관. 위젯 값은 매 실행마다 model에서 채우므로 필터 전환·더 보기·페이지 왕복 뒤에도 값이 유지됩니다.
- 추천에 없던 ETF: 목록 아래 '추천에 없던 ETF 더하기' 펼침의 다중 선택. 더하면 0%로 목록에 들어오고, 빼면 0%로 돌아갑니다.
- 되돌리기 = 추천 비중·더한 ETF 초기화(필터 유지). 예산 변경은 비중 유지. 추천(성향·예산)이 바뀌면 새 추천으로 다시 시작.
- 레이아웃: 맨 위 요약(예산 입력 · 담은 비중 막대 · 실제로 사는 돈 · 남는 현금) → 왼쪽 목록 : 오른쪽 **비교 패널** ≈ 1.15 : 1.
  - 비교 패널은 목록 바로 오른쪽 위에 있고 `position: sticky`로 목록을 스크롤해도 화면에 남습니다. 패널이 화면보다 길면 패널 안에서 스크롤합니다(`max-height: 100vh−24px`). 화면 높이 680px 이하·폭 900px 이하(모바일)에서는 고정을 풀고 한 열로 내려갑니다.
  - 탭: **구성 차이**(추천안 vs 내 구성 자산군 막대, 자산군별 변화량, 많이 바뀐 상품 5개) · **과거 성과**(시작값 100 선 그래프, 연환산 수익률·변동성·최대 낙폭 추천안/내 구성/차이 표, 기간·가정 한 줄) · **구성 도넛**.
  - 실제 매수표·CSV·낱말 풀이는 아래 펼침으로 옮겼습니다.
- 색: 주식 빨강·주황 / 채권 파랑 / 다른 자산 초록 / 자산배분 보라 / 현금 회색 그대로.

## 6. Codex 검수 후속 보완 (2026-11-14)

### 6-1. 제작 예산이 페이지 왕복 뒤 1원으로 돌아가던 버그
- 원인: 예산이 위젯 key(`existing_recommendation_c_budget`)에만 있었고, Streamlit은 화면에 그리지 않은 위젯 key를 지워요. 기업 화면에 다녀오면 입력칸은 최솟값 1, 계산은 이전 값을 쓰는 불일치가 생겼어요.
- 수정: 예산을 비중과 같은 model(`session_state['existing_recommendation_c_model']['budget']`)에 보관. 입력칸은 매 실행마다 model 값으로 채우고, 숫자 입력·+/− 버튼은 `on_change` 콜백으로 model에 반영해요. 표시·계산 모두 model 값 하나만 씁니다.
- 규칙 유지: '추천 비중으로 되돌리기'는 직접 정한 예산을 그대로 둡니다. 설문 예산(기본 예산)이 바뀌면 새 기본 예산을 따릅니다.
- 회귀 테스트 `test_editor_budget_persists_across_pages`: 기본 생성 1,000만원 → 12,300,000 입력 → company·result 왕복 → 입력값 = model = (실제로 사는 돈 + 남는 현금) = 12,300,000, 비중 유지 → +버튼 12,310,000 → 되돌리기 후 유지 → 설문 예산 500만원으로 바뀌면 500만원.
