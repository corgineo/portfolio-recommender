## 미확인·한계
- 실제 사용자(초보자) 테스트는 하지 않았어요. 문구 쉬움 정도는 작성자 판단이에요.
- 연습하기의 자산 종류 칩은 상품 자체의 종류로 합산해, 결과 화면의 '여러 자산 묶음' 10%가 채권·다른 자산에 더해져 보여요(캡션으로 설명).
- 스크린리더 낭독 순서, 200% 확대, 태블릿 폭(768px 전후)은 따로 확인하지 않았어요.
- Streamlit 기본 슬라이더·셀렉트 디자인은 CSS로 일부만 조정했어요. `st.components.v1.html` 지원 종료 경고는 기존과 같아요.
- 결과 '이렇게 사면 돼요' 예시는 1주 단위라 저예산(예: 100만원)에서는 35개 상품이 빠지고 현금이 커져요(기존 계산 그대로).
